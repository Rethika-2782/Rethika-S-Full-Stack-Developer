## 📦 Running Locally

### 1. Launch Frontend
Simply open `index.html` in any modern web browser or serve via:
```bash
npx serve .
```

### 2. Launch MongoDB Contact Concierge API
```bash
cd server
npm install
npm start
```
*API will run at `http://localhost:5000` with automated health monitoring.*
